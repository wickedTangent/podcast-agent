## Topics Covered

### Scheduled Tasks as the Gateway to Autonomous Agents
Jordan Wilson frames scheduled tasks as the "gateway drug" to full autonomous agent adoption. The core idea is that most repetitive AI use cases can be automated into scheduled workflows, letting users wake up to completed work rather than pushing buttons manually. Wilson argues that agentic adoption has been slower than it could have been because companies buried these features and made them hard to find, with frequent name and interface changes across platforms. He describes the "unlearning and rebuilding" process -- shifting from task-oriented thinking to outcome-oriented thinking, working backwards from the end goal to design a workflow that runs on its own.

### Google Gemini Scheduled Actions
Gemini's scheduled actions are described as the weakest of the three platforms. They are hard to find (buried in Settings rather than the main navigation), buggy, extremely limited in features and UI, and cannot be set up through normal chat (attempting to do so produces false positives). A critical limitation is that scheduled actions will auto-disable if not used or checked in on. Gemini's scheduled actions also do not use connected data (Gmail, Drive, etc.), and cannot use Canvas mode for visual outputs. In Wilson's test, Gemini fired at the correct time and retrieved stock data, but failed to produce an interactive visual and returned incorrect price data (reported Google up ~1% when it was actually down ~4%).

### ChatGPT Scheduled Tasks: Model Selection, Work Mode, and Open-Ended Tasks
ChatGPT scheduled tasks are the most feature-rich of the three platforms. Key capabilities include:
- **Model selector:** When scheduling conversationally through the main chat (rather than the scheduled tasks page), users can choose the exact model and reasoning level -- a feature the scheduled page omits. Wilson recommends using the most powerful model available since scheduled tasks run while sleeping.
- **Work mode with virtual computer:** ChatGPT Work has its own dedicated virtual computer and browser, enabling complex multi-step web interactions (scrolling, filtering, clicking) that static page scanning cannot handle. This is unique to ChatGPT.
- **Open-ended tasks:** ChatGPT supports tasks without a fixed schedule (e.g., "check competitor pricing and tell me when it changes"), which it triggers automatically.
- **Custom scheduling:** Supports custom frequencies (e.g., "every other Tuesday") and end dates -- features Claude and Gemini lack.
- **Memory integration:** Uses Dream v3 memory for deeply personalized automation, contextualizing tasks with user history and data.
- **Sites integration:** ChatGPT Sites (available on web, Plus, and Pro plans) can be scheduled to auto-update, creating persistent dashboards.
- **Connectors and Skills:** Full access to Gmail, Gmail, and other integrations.

### Claude Scheduled Tasks and Scheduled Routines
Claude offers two distinct scheduling paths on the web:
- **Scheduled Tasks (Home/Code interface):** Equivalent to ChatGPT's scheduled tasks. Supports model selection (but not reasoning level), connectors, skills, project integration, and per-task approval levels. Accessible from the sidebar or conversationally.
- **Scheduled Routines (Claude Code):** More powerful and unique features include:
  - **API token triggers:** Routines can be triggered by an external API token, enabling integration with Zapier and 6,000+ platforms. This allows event-driven automation (e.g., trigger a routine when a form submission arrives) rather than time-based scheduling alone.
  - **Desktop sync:** Unlike scheduled tasks, routines sync with Claude Desktop.
  - **Messaging alerts:** Routine-level Slack notifications for when tasks complete.

Wilson notes Claude's routines are simpler to set up than Claude Code itself -- non-technical users can configure them through natural language. However, Claude lacks cross-chat/cross-code memory, meaning routines cannot leverage the same contextual history that ChatGPT's Dream v3 memory provides.

### Platform Comparison: Stock Dashboard Test
Wilson ran an apples-to-apples test across all three platforms with the same prompt: create an interactive daily dashboard showing stock prices and news for 10 AI-related companies (NVIDIA, Alphabet, Microsoft, Broadcom, Meta, TSMC, Micron, AMD, Oracle, Palantir).

Results:
- **ChatGPT:** Best result. Produced a visually polished interactive dashboard with AI Basket Pulse, winners/losers breakdown, watchlist functionality, and detailed news per stock. Used Sites feature. Slightly older news items but excellent UI/UX.
- **Claude:** Good result. Produced clean HTML with interactive elements (light/dark mode, ticker symbols, percentage changes, expandable news). Did not use the Artifact feature as requested but still delivered a functional dashboard.
- **Gemini:** Failed. Fired at the correct time and retrieved stock prices but did not produce Canvas output. Required a follow-up prompt to produce any visualization at all. Returned incorrect price data (reported Google up when it was down).

### Best Practices for Scheduling AI Workflows
Wilson recommends these approaches for identifying what to schedule:
1. **Audit your manual tasks:** Use ChatGPT Work or Claude to identify repetitive tasks you currently do manually inside these platforms.
2. **Analyze browser history:** Review your most-viewed websites and tie them to deliverables -- schedule automated checks of those sites.
3. **Build a daily triage dashboard:** The 2026 equivalent of "improve this email" -- an automatically updated dashboard pulling from mail, calendar, Slack, Teams, CRM, and KPIs, telling you where to start each day.
