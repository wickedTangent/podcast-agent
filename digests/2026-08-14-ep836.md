### Adobe Unified Plugin for ChatGPT
Adobe launched a unified plugin for ChatGPT that consolidates more than 70 tools from across its creative and productivity suite -- including Photoshop, Firefly, Acrobat, Express, Premiere Pro, Lightroom, Illustrator, InDesign, and Adobe Stock -- into a single integration. Users describe what they want to do and the plugin automatically selects the right Adobe tools, replacing the separate Adobe app connectors that were previously available in ChatGPT. The plugin is free for all ChatGPT users, with generative AI features requiring an Adobe account and Creative Cloud sync available to subscribers. It also works inside Claude and Copilot, though the ChatGPT integration is the most robust version seen to date.
- [Introducing Adobe for ChatGPT (Adobe Blog)](https://blog.adobe.com/en/publish/2026/08/06/introducing-adobe-chatgpt-create-edit-get-work-done-all-in-chatgpt) - Official announcement from Adobe

### Meta Muse Code and Muse Spark 1.2
Meta released Muse Code, a terminal-based coding agent powered by its new Muse Spark 1.2 model. Muse Code supports parallel sub-agents, worktree isolation, and a crash-safe event log that records every tool call, agent action, and edit for auditability and recovery. The Muse Spark 1.2 model has a 1,000,000-token context window and competitive benchmarks on DeepSWE. Full API pricing is $2.50 per million tokens in and $4.25 per million tokens out, but Meta also introduced a "contributor tier" at 10 cents per million tokens in and 20 cents per million tokens out for users who opt in to having their code used for training -- roughly a 95% discount.
- [Meet Muse Spark 1.2 and Muse Code (Meta Developer)](https://developer.meta.com/ai/resources/blog/build-with-muse-code/) - Official Meta announcement
- [Introducing Muse Code and Muse Spark 1.2 (Meta AI Research)](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2) - Research blog with technical details
- [Muse Code Product Page (Meta)](https://developer.meta.com/ai/products/muse-code/) - Product page with setup and pricing

### Alibaba Qwen 3.8 Max
Alibaba officially launched Qwen 3.8 Max, a 2.4-trillion-parameter mixture-of-experts model with a 1,000,000-token context window that supports text, images, and video. It ranks fifth in Text Arena and second in Vision Arena, placing it in the same tier as GPT-5.6, Claude Opus 5, and Kimi K3. The open-weight base model (Qwen3.8-2.4T-A95B) is available on Hugging Face under a custom Qwen license rather than Apache 2.0. Alibaba also announced plans to begin charging enterprise users a share of their generated revenue starting the following week. The API is OpenAI-compatible, making it a drop-in replacement with a base URL and model ID change.

### Gemini Notebook (Agentic)
Google rebranded NotebookLM as Gemini Notebook and rolled out agentic features to all paid users. The new version runs on Gemini 3.5 with the Antigravity harness and includes 100 built-in skills. It features a secure cloud computer that writes and executes real code against user sources, auto-generates charts, spreadsheets, slide decks, and PDFs, and can now query the web (with user confirmation). Output formats have expanded beyond the previous eight options to include PDF, DOC, and PNG. Free users still see Gemini Notebook but lack the agentic code execution and advanced output formats.
- [Gemini Notebook (Google)](https://notebook.google/) - Official product page
- [Google Big NotebookLM Upgrade (Nokia Poweruser)](https://nokiapoweruser.com/google-notebooklm-gemini-3-5-upgrade-agentic-research/) - Coverage of the upgrade details

### Agent Plugins (Open Standard)
OpenAI announced Agent Plugins, an open, vendor-neutral standard for packaging AI agent extensions into a single distributable format. The standard bundles agent skills, MCP server configurations, and JSON files into a single folder with a plugin.json manifest. It is backed by AWS, Cursor, GitHub Copilot, Microsoft, Vercel, and Google, but notably excludes Anthropic. The initiative was initiated by Vercel with broad industry support. The specification and documentation are available at agent-plugins.org, and it works across ChatGPT, Codex, Cursor, Google, GitHub Copilot, and VS Code.
- [Agent Plugins (Official Site)](https://agent-plugins.org/) - Official specification page
- [Agent Plugins Specification (GitHub)](https://github.com/agentplugins/agent-plugins-spec) - Versioned specification repository
- [Agent Plugins: Package Your Skills (Google Developer Blog)](https://developers.googleblog.com/agent-plugins-package-your-skills-tools-and-more/) - Google's announcement

### Cloudflare OS
Cloudflare announced Cloudflare OS, an open-source AI workspace built on Cloudflare Workers that it originally developed internally for its own company. Every employee gets a browser-based agent workspace with governed access to internal systems, research documents tied to live data, automated workflows, and shareable internal apps -- no developers required. Thousands of Cloudflare employees across all teams already use it daily. It competes with ChatGPT Work, Claude Cowork, and Gemini Enterprise but is free, open-source, and runs on the customer's own Cloudflare account using their own access policies. Users must bring their own models through the Cloudflare AI Model Gateway, with spend caps available. A managed version with implementation partners is planned but has no announced date.
- [Cloudflare OS Press Release (Cloudflare)](https://www.cloudflare.com/en-ca/press/press-releases/2026/cloudflare-os-is-the-first-ai-workspace-built-around-how-companies-actually-work/) - Official announcement (August 4, 2026)

### MiniMax H3 Video Model
MiniMax released H3, a general-purpose omni-modal generation model that supports unified understanding of text, images, video, and audio as a single context. It generates video with native stereo audio at up to 2K resolution for up to 15 seconds. H3 ranked number one in video editing and number two in text-to-video on Artificial Analysis, called the "strongest open-weights model by far." The model is available via the MiniMax API for hosted generation, and the quantized weights are available on Hugging Face for local deployment -- though local inference on consumer hardware (e.g., 16-32GB MacBook) takes 20-30 minutes for a 15-second clip. The license currently excludes the US, EU, UK, and South Korea from local deployment (API-only in those regions).

### GPT-5.6 Luna Free Unlimited Access
OpenAI made GPT-5.6 Luna the default model for free and Go ChatGPT users, giving them unlimited text chats on a model roughly on par with Claude Sonnet 5. For paid Plus and Pro users, OpenAI merged the instant and thinking models into one with a reasoning slider that controls how much reasoning is applied to each response, and claims 68% fewer responses containing factual errors in financial, medical, and legal topics compared to GPT-5.6 Instant. This brings the total ChatGPT user base with access to frontier-level models to approximately one billion people.
