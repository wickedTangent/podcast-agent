## Topics Covered

### NotebookLM Rebranded to Gemini Notebook
Google officially rebranded NotebookLM as Gemini Notebook on July 16, 2026, moving the popular source-grounded AI research tool under the Gemini brand umbrella. The product remains standalone and retains its core differentiator: chat responses grounded exclusively in user-uploaded sources (PDFs, Google Docs, YouTube videos, web URLs, audio, and pasted text -- up to 50 sources per notebook). The rebrand signals a functional shift from a document reader to an agentic research workspace.

### Collections Feature for Notebook Organization
Google added Collections to Gemini Notebook, allowing users to group related notebooks into customizable folders. This addresses a common organizational challenge as users accumulate notebooks across different projects and research areas. Collections sit at the notebook level, not the source level, making it easier to navigate large notebook libraries.
- [Google adds handy Collections feature to Gemini Notebook](https://www.androidauthority.com/gemini-notebook-collections-feature-3689444/) - Android Authority coverage

### Automatic Google Drive Syncing
Gemini Notebook now automatically syncs with Google Drive, so changes to Drive files (Docs, Sheets, Slides) are reflected in notebooks without manual re-uploading. The sync runs every few minutes when the browser extension is active. This feature was initially added to NotebookLM in May 2026 and carried forward to Gemini Notebook. A companion feature lets Workspace Studio users automatically add Drive sources to notebooks as part of recurring workflows.
- [Keep your sources up to date with automatic Drive syncing in NotebookLM](https://workspaceupdates.googleblog.com/2026/05/keep-your-sources-up-to-date-with-automatic-Drive-syncing-in-NotebookLM.html) - Official Google Workspace update
- [Automatically add sources to your Gemini Notebooks in Workspace Studio](https://workspaceupdates.googleblog.com/2026/08/automatically-add-sources-to-your-Gemini-Notebooks-in-Workspace-Studio.html) - August 2026 Workspace Studio integration

### Gemini App and Google Search AI Mode Access
Personal Gemini Notebooks are now accessible inside the Gemini app and will soon be accessible inside Google Search's AI Mode. This creates bidirectional sync between Gemini Notebook and Gemini: changes made in one app (renaming notebooks, adding sources, updating custom instructions) propagate to the other. Notebooks in Gemini also serve as a project base, connecting the Gemini app with the NotebookLM research engine.
- [Notebooks in Gemini Apps - Gemini Notebook Help](https://support.google.com/gemininotebook/answer/17003757?hl=en) - Official Google Help documentation

### New Output Formats (11+ Formats)
Gemini Notebook expanded far beyond NotebookLM's original output constraints. Users can now generate PDFs, PNGs, Word documents, Excel spreadsheets, PowerPoint presentations, Markdown files, charts, images, interactive reports, audio overviews, video overviews, mind maps, flashcards, quizzes, infographics, and data tables. The image generation uses Nano Banana Pro (Gemini 3 Pro Image), which offers significantly better reasoning, text rendering, and resolution than the original Nano Banana (Gemini 2.5 Flash Image).

### Secure Cloud Computer with Code Execution
Each Gemini Notebook now has its own isolated cloud computer (sandbox) that can write and execute code natively for data analysis, calculations, and research tasks. This is powered by Google's Antigravity agent harness and gives notebooks over 100 curated software skills. Code execution runs in a secure, isolated environment -- though security researchers in 2026 identified sandbox escape vulnerabilities in several AI coding agents including Gemini CLI and Antigravity.

### Agentic Intelligence via Gemini 3.5 and Antigravity
Gemini Notebook is now powered by Gemini 3.5 Flash and Google's Antigravity agent harness, making it truly agentic by default. Unlike the previous non-reasoning NotebookLM, Gemini 3.5 enables chain-of-thought reasoning, tool calling, and autonomous multi-step workflows. The Antigravity framework allows notebooks to plan, execute code, retrieve information, and produce synchronized multi-format outputs from a single prompt. Gemini 3.5 Flash is described as delivering "frontier performance for agents and coding" with excelling capability on complex long-horizon tasks. The Antigravity platform is also available separately via the Interactions API and Google AI Studio for developers.

### Grounded Search: Web Research Integration
A notable behavioral change: while Gemini Notebook remains grounded in user sources by default, it can now perform web research when sources don't contain the answer -- but only after explicitly asking the user for permission first. This is a departure from NotebookLM's strict 100% source-grounded approach. The host notes this was triggered when the Antigravity harness was already active from a prior prompt, suggesting the web research capability activates after initial agentic tool use. Users should review chain-of-thought to understand when external research is being used alongside source-grounded answers.
