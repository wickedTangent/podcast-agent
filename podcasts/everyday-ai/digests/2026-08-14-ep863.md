## Topics Covered

### Scheduled Agentic Context Carry (SACC)
Jordan Wilson coins the term "Scheduled Agentic Context Carry" (SACC) to describe a new workflow paradigm emerging across the AI industry. SACC combines four elements: (1) scheduling -- agents that run on a cadence rather than only when prompted, (2) context -- persistent memory of user preferences, company data, and dynamic pipelines, (3) agentic capability -- the ability to call tools and take actions across connected apps, and (4) carry -- the capacity to retain information between runs. Wilson argues this is the critical stepping stone between reactive chatbots and fully autonomous agents, as true autonomy remains limited by safety concerns and guardrail fragility.

### OpenAI Workspace Agents and Scheduled Tasks
OpenAI launched workspace agents in ChatGPT for Business, Enterprise, and Edu plans, enabling teams to build shared agents that handle complex, long-running workflows across connected tools. Agents can be run on schedules via a dedicated Scheduled page available on web, mobile, and desktop. The agents use connected apps (Gmail, Slack, Notion, Teams, Outlook, Google Drive) and MCP servers to gather information and take action without step-by-step guidance. OpenAI also added scheduled work and persistent memory to the Codex platform, allowing agents to retain context across runs.

### Google Gemini Enterprise Agent Platform
At Google Cloud Next '26 (April 2026), Google retired Vertex AI and launched the Gemini Enterprise Agent Platform as its unified environment for building, scaling, governing, and optimizing AI agents across the enterprise. The platform combines access to frontier Gemini models with a secure development framework, enabling enterprises to deploy agents that execute complex, multi-step workflows capable of running for hours or days. Wilson highlights this as part of the broader shift toward scheduled, context-carrying agents rather than one-off chat interactions.

### Claude Code Routines
Anthropic introduced Claude Code Routines in research preview, allowing developers to save a Claude Code configuration (prompt, repositories, and connectors) and run it automatically on a schedule, from an API call, or in response to an event. Routines execute on Anthropic-managed cloud infrastructure, so they run independently of the user's laptop. Wilson cites this as one of the catalysts that "forced the hand" of all major AI companies to build scheduled agent capabilities, with the OpenClaw movement in February-March 2026 as a key driver of industry attention.

### Microsoft Copilot Cowork
Microsoft Copilot Cowork, powered by Anthropic's technology, became generally available in June 2026 after a Frontier program launch. Cowork carries out long-running, multi-step tasks across the Microsoft 365 environment -- sending emails, scheduling meetings, creating documents, posting in Teams, and managing calendars. With Work IQ, Cowork maintains full context of a user's work. Wilson notes that Copilot Cowork represents the "co-working" paradigm where the AI agent and human collaborate, with the agent carrying context across Microsoft's app ecosystem.

### Perplexity Computer and Scheduled Tasks
Perplexity Computer, launched in February 2026, is described as a general-purpose digital worker that operates the same interfaces a human user does. Wilson mentions Perplexity alongside the "big four" (Anthropic, OpenAI, Microsoft, Google) as having shipped scheduled agent capabilities.

### 1M Token Context Windows and the Technology Enabler
Wilson identifies the explosion of context window sizes as the key technology enabling SACC. Anthropic made its 1M token context window generally available on Claude Sonnet 4.6 and Claude Opus 4.6 (March 2026) with standard pricing and no per-token surcharge above 200K tokens. OpenAI's Codex supports a 1M token context window with GPT-5.6 Sol, available to ChatGPT account users. Wilson explains that these massive context windows allow agents to hold weeks of regular usage working memory at once, making persistent context between scheduled runs practical for the first time.

### From Chatbots to Autonomous Agents: The Stepping Stone
Wilson frames SACC as the intermediate phase between reactive chatbots and fully autonomous AI agents. He argues that fully autonomous agents (where you give a goal and the agent executes without human intervention) are not yet reliable due to safety concerns, guardrail fragility, and data corruption risks. Autonomous narrow agents exist for very specific, well-defined tasks, but general autonomy is still years away. SACC -- scheduled agents that carry context and require human oversight -- is the practical stepping stone that businesses should adopt now. He calls this the "hidden workflow" that bridges today's tools to the future of AI.
