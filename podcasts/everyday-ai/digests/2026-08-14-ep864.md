## Topics Covered

### Headless Software Overview
Jordan Wilson introduces the concept of "headless software" -- applications being rebuilt from the ground up to be operated by AI agents rather than humans through graphical interfaces. The core thesis: just as Waymo driverless cars changed the role of the human driver (no steering wheel, no pedals), headless software shifts humans from operators to overseers. Agents call APIs, invoke MCP tools, and run CLI commands directly, while the software surface (Slack, WhatsApp, voice) becomes the interaction layer. This represents a fundamental shift from the 1990s paradigm of clicking and typing to a new model where "the agent becomes the operator."

### Salesforce Headless 360
Launched at Trailblazer DX, Salesforce Headless 360 turns every CRM workflow into a callable API, MCP tool, or CLI command. Key components include: (1) 60+ new MCP tools and 30+ preconfigured coding skills for coding agents like Claude Code, Cursor, Codex, and Windsurf; (2) Agentforce Experience Layer -- a UI service that renders rich interactive components (flight status cards, rebooking workflows) natively inside Slack, ChatGPT, Claude, Gemini, Teams, and any client supporting MCP apps; (3) Agent Fabric -- a governed control plane for multi-vendor agent orchestration with deterministic orchestration and centralized governance. Agentforce ARR reached $1.2 billion in Q1 FY2027, up 205% year over year. Salesforce runs three pricing models simultaneously: per-conversation, Flex Credits (~$0.10/action), and Agentic ELA ($125+/user/month).

### OpenAI Workspace Agents
OpenAI launched Workspace Agents for all team accounts, enabling drag-and-drop agent builders that connect natively to enterprise software including Slack, Salesforce, Google Drive, and Notion. Agents can run on schedule at cloud scale. The feature requires a new identity and governance layer for teams. At the time of the episode, the feature was included through May 6 for team accounts ($20-$200/month plans). This represents a shift from human-prompted AI (Phase 2) to headless orchestration where humans set up agents and oversee outcomes rather than manually executing steps.

### MCP and A2A Protocols: The USB-C of AI
Two open protocols are becoming the standard infrastructure for agent connectivity. **MCP (Model Context Protocol)**, originally built by Anthropic, connects AI applications to external systems like a universal USB-C. It now has 10,000+ active public MCP servers and has been adopted by ChatGPT, Cursor, Gemini, Microsoft Copilot, and VS Code. Anthropic donated MCP to the Agentic AI Foundation (AAIF), a Linux Foundation directed fund co-founded by Anthropic, Block, and OpenAI with support from Google, Microsoft, AWS, Cloudflare, and Bloomberg. MCP SDKs see 97M+ monthly downloads. **A2A (Agent-to-Agent Protocol)**, launched by Google, lets agents from different platforms hand off entire workloads to each other. It supports HTTP, SSE, and JSON-RPC, with over 50 technology partners including Atlassian, Salesforce, SAP, ServiceNow, MongoDB, and PayPal. While MCP focuses on data sharing and tool access across AI platforms, A2A focuses on handing off complete tasks between agents.

### Per-Seat Software Pricing Disruption
The software industry's per-seat pricing model is facing structural disruption as AI agents absorb work previously done by humans. IDC's European software research lead stated "SaaS is not dead, but it is metamorphosing." IDC's FutureScape #US53860925 predicts that by 2028, 70% of software vendors will refactor pricing away from pure per-seat models toward consumption, outcome-based, or organizational capability metrics. Current pricing experiments include: Salesforce's Flex Credits (~$0.10/action), HubSpot's Customer Agent ($0.50/resolved conversation), GitHub Copilot's token-based billing (June 2026), and Sierra's outcome-based model (~$1.50/resolved interaction). 41% of AI vendors now use hybrid pricing (base + usage), up from 27%, per Bessemer's 2026 AI Pricing Playbook. 40%+ of enterprise SaaS spend is projected to shift to usage, agent, or outcome pricing by 2030 per Gartner.

### AI Bot Traffic to Exceed Human Traffic by 2027
Cloudflare CEO Matthew Prince stated at SXSW that AI bot traffic will exceed human online traffic by 2027. Before generative AI, internet traffic was ~20% bot traffic (primarily Google's crawler). AI agents visit roughly 1,000 times more sites than human shoppers -- a human shopping for a camera might visit 5 sites, while an agent visits 5,000. Cloudflare projects this automated traffic growth has no slowdown in sight, requiring new infrastructure like on-demand AI agent sandboxes. This has implications for marketing funnels, e-commerce, and whether future websites are optimized for humans or for AI agents (GEO/AIEO).
